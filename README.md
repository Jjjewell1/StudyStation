# StudyStation

A coursework tracker for VCCS Canvas sync.

Live: nightly Canvas→Postgres sync. 5 courses / 243 assignments / 217 due dates synced.

Stack: Postgres (pgvector), Python (SQLAlchemy 2 + psycopg3), supercronic cron.

Deploy: Docker Compose on Coolify. Session JSON in env var.
